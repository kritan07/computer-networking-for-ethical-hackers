# 🌐 Computer Networking for Ethical Hackers

A complete **Computer Networking course** designed to build a strong foundation for **Cybersecurity and Ethical Hacking**.

## 🎯 Why This Repository?

Networking is a fundamental skill for ethical hackers. This repository covers networking concepts from **beginner to advanced**, with practical learning and security-focused topics.

## 📚 Topics

* Networking Fundamentals
* DNS
* OSI Model
* TCP/IP Model
* IP Addressing
* Subnetting
* TCP & UDP
* Ports & Protocols
* Routing & Switching
* Network Security
* Wireshark
* Networking for Ethical Hacking

