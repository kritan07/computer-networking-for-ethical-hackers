# Introduction
------

***Computer networking is the process of connecting computers, servers and other devices so they can communicate and exchange data with each other. It enables devices to share resources such as files, applications, printers and internet connections. Networks can be small, such as a home or office network or massive, like the Internet. Understanding computer networking is a fundamental skill for IT professionals, system administrators, cloud engineers and cybersecurity professionals.***
