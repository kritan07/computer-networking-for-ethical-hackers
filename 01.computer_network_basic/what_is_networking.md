# Introduction
------

***Computer networking is the process of connecting computers, servers and other devices so they can communicate and exchange data with each other. It enables devices to share resources such as files, applications, printers and internet connections. Networks can be small, such as a home or office network or massive, like the Internet. Understanding computer networking is a fundamental skill for IT professionals, system administrators, cloud engineers and cybersecurity professionals.***

## Network Types Based on Size

Computer networks are grouped by size and geographic range. The main types from smallest to largest are Personal Area Network (PAN), Local Area Network (LAN), Metropolitan Area Network (MAN), and Wide Area Network (WAN). 

### 1. LAN (Local Area Network)
A Local Area Network (LAN) is a computer network that connects multiple devices—such as computers, servers, printers and network devices—within a limited geographical area, such as a home, office, school or building, allowing them to communicate and share resources.

**How LAN works**
In a LAN, devices are connected using Ethernet cables or Wi-Fi. Network devices such as switches, routers and access points help manage communication between these devices.
